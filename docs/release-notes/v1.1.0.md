# VoiceDuck 1.1.0

本版本新增安全的“通话音乐分享”：对方听到物理麦克风与本地音乐，你的耳机只听到音乐和正常通话声音。

## 亮点

- 内置本地音乐播放器，支持 MP3、WAV、M4A、AAC、WMA 与 FLAC。
- 物理麦克风与音乐经过独立增益、48 kHz 浮点混音和最终限幅后送给对方。
- 音乐单独送真实耳机，通话输出不进入混音，因此没有麦克风延迟回听和远端回声。
- 内置未修改的标准 VB-CABLE Driver Pack 45，只增加一组虚拟播放/录音端点。
- 安装前校验压缩包、安装程序哈希、Windows Authenticode 和发布者。
- 驱动只在明确确认后安装；不改系统默认设备、不自动重启。检测到通话音频会话时会显示预计耗时和中断风险，并默认选择“否”。
- 暂停音乐时麦克风保持在线；停止分享会完整释放实时音频流。
- 保留原有自动闪避、音量恢复、托盘与开机启动功能。

## 首次使用

1. 下载并完整解压 `VoiceDuck-1.1.0-portable.zip`。
2. 结束当前通话并退出通话应用。
3. 打开“通话音乐分享”，点击“安装内置驱动”，按提示手动重启 Windows。
4. 在微信/QQ 内把输入设备选择为 `CABLE Output`，输出仍选择真实耳机。
5. 回到 VoiceDuck 选择麦克风、耳机和本地音乐，开始分享。

自动闪避无需安装驱动。
