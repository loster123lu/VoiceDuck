# VoiceDuck 1.1.0

本版本新增“实时通话声音分享”：直接监听当前耳机或音箱的播放声，与物理麦克风混合后发送给对方，无需选择本地音乐文件，也不改变音乐软件的输出设备。

## 亮点

- WASAPI 实时监听所选真实播放设备，支持来自播放器、浏览器、游戏等任意软件的声音。
- 物理麦克风与播放声经过独立增益、48 kHz 浮点混音和最终限幅后送给对方。
- 播放声使用约 350 ms 安全延迟；检测到通话应用输出时自动丢弃对应设备声，防止远端回声，麦克风保持在线。
- 内置未修改的标准 VB-CABLE Driver Pack 45，只增加一组虚拟播放/录音端点。
- 安装前校验压缩包、安装程序哈希、Windows Authenticode 和发布者。
- 驱动只在明确确认后安装；不改系统默认设备、不自动重启。检测到通话音频会话时会显示预计耗时和中断风险，并默认选择“否”。
- 安装或卸载后持续等待 Windows Audio 与真实端点稳定；新增“恢复声音”按钮，可在设备列表意外为空时重启音频服务。
- 设备列表与自动闪避统一使用同一套 Core Audio 封装，避免同时运行时的 COM 类型冲突。
- 暂停播放声时麦克风保持在线；停止分享会完整释放实时音频流。
- 开始分享后，“停止分享”按钮会以醒目的鲜红色持续显示，便于紧急停止。
- 可在开始分享时自动把 Windows 默认麦克风切到 CABLE Output；停止、异常结束或退出后恢复开始前的真实麦克风，并提供崩溃后的下次启动恢复。
- 新增与深色界面匹配的 VoiceDuck 程序、窗口和托盘图标。
- 分享开始与停止合并为同一个主按钮，运行时由蓝色切换为鲜红色。
- 精简音乐分享页面，移除重复说明和额外路由确认，选择设备后即可直接开始分享。
- 修复所有滑轨点击后只按大步长偏移的问题，点击轨道现在会落到对应数值。
- 新增无需更改输出驱动的耳机音量保护，可限制系统音量、压低突发峰值并缓慢恢复。
- 保留原有自动闪避、音量恢复、托盘与开机启动功能。

## 首次使用

1. 下载并完整解压 `VoiceDuck-1.1.0-portable.zip`。
2. 结束当前通话并退出通话应用。
3. 打开“通话音乐分享”，点击“安装内置驱动”，等待声音设备稳定检测完成；仅在界面明确提示时手动重启 Windows。
4. 让微信/QQ 的输入跟随“系统默认设备”，输出仍选择真实耳机；在 VoiceDuck 保持勾选“自动切换并恢复系统默认麦克风”。
5. 回到 VoiceDuck 选择真实麦克风和当前正在播放声音的耳机/音箱，开始分享；停止后会恢复原默认麦克风。

实时监听会发送所选设备上的全部播放声。Windows 10 无法稳定只抓取单一音乐进程，因此通知音等也可能被分享；对方讲话时，播放声会为了回声保护短暂静音。

自动闪避无需安装驱动。
