# VoiceDuck 1.0.0

首个公开版本，覆盖微信、QQ、Discord、Teams、Zoom 等通话场景，以及网易云音乐、QQ 音乐、Spotify、MusicBee、VLC、PotPlayer 等背景播放应用。

## 亮点

- 通话应用与背景应用分别选择，不默认压低全部系统声音。
- 同时监测所有活动播放设备和同一进程的多个音频会话。
- 防提示音触发延迟与断句保持，减少误触和音量抽动。
- 按原音量比例平滑降低，暂停或退出时精确恢复。
- 支持闪避期间在 Windows 音量混合器中手动调整。
- 中文界面、四组预设、托盘常驻与开机启动。

## 安装

下载 `VoiceDuck-1.0.0-portable.zip`，解压后运行 `VoiceDuck.exe`。程序不需要安装，不会添加驱动，也不需要管理员权限。

## 校验

发布包的 SHA-256 会附在 Release 页面。可使用以下命令核对：

```powershell
Get-FileHash .\VoiceDuck-1.0.0-portable.zip -Algorithm SHA256
```

## 注意

便携版未使用商业代码签名证书，Windows 可能显示未知发布者提示。源码、构建脚本和 CI 工作流均在仓库中公开。
